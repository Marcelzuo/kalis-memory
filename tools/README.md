# 米迦勒团队 · 共享工具

## collector.py — 信息采集系统
19 个直连信息源，四兄弟各管一摊。
```
python3 collector.py scan frontend   # 玛门·前端
python3 collector.py scan browser    # 撒旦·浏览器
python3 collector.py scan review     # 路西法·审查/AI
python3 collector.py scan business   # 老板·商业情报
python3 collector.py custom "关键词"  # 自定义
```

## search.py — 搜索引擎
多渠道搜索：DDG、微信搜一搜、B站、豆包AI。
```
python3 search.py text "关键词"
python3 search.py news "关键词"
python3 search.py weixin "关键词"
python3 search.py bilibili "关键词"
python3 search.py doubao "问题"
```
