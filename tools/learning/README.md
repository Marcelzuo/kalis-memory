# 珞妤 · WorkBuddy 初中全科学习方案

> 米迦勒团队 · 四兄弟联合出品 · 2026.07

---

## 一、方案概述

围绕 **WorkBuddy** 打造初中全科智能学习系统。核心功能：

| 功能 | 覆盖 | 实现方式 |
|:--|:--|:--|
| 错题分析 | 数学/语文/英语 | WorkBuddy Skill → 拍照即分析 |
| 错因归类 | 5类错因体系 | 自动分类 + 路西法审核 |
| 新题生成 | 数学为主 | 同知识点 3 道梯度题 |
| 学习计划 | 全科 | 基于错题库的艾宾浩斯复习表 |
| 作文批改 | 语文/英语 | 多维度评分 + 修改建议 |

---

## 二、模型策略

**全科统一用 DeepSeek R1。** 老板已付费的 Key 直接复用，零额外费用，零切换。

### 为什么 DeepSeek R1 够用全科？

- **数学**：chain-of-thought 推理，国内 MATH 基准第一。覆盖奥数到高中。
- **语文**：中文能力足够批改初一作文、分析阅读理解。
- **英语**：初中英语语法和写作完全胜任。
- **学习计划**：逻辑推理型任务，R1 的强项。

### 双重保险（保证数学准确率）

1. Skill 内置**交叉验证**：同一题用两种方法算，答案不一致就报警
2. **路西法抽查**：每周从错题库随机抽 3 题独立验算
3. 答案不一致 → 标记 ⚠️ 人工复核

## 四、部署步骤

### 在女儿电脑上

```bash
# 1. 把整个 learning/ 文件夹拷到女儿电脑
# 2. 运行部署脚本
bash deploy.sh

# 3. 编辑模型配置 → 填入 API Key
open ~/.workbuddy/models.json

# 4. 重启 WorkBuddy
```

### API Key

**直接用老板已付费的 DeepSeek Key。** 零额外注册、零额外费用。

把 Key 填入 `models.json` 即可。

### 在爸爸电脑上（路西法抽查）

```bash
# 每周运行一次
bash lucifer-review/verify.sh
# 报告自动生成在 ~/路西法-抽查报告-日期.md
```

## 五、使用方式

女儿在 WorkBuddy 里这样说：

| 场景 | 怎么说 |
|:--|:--|
| 数学错题 | "帮我分析这道题：[粘贴题目]" 或直接截图 |
| 语文作文 | "帮我批改这篇作文：[粘贴]" |
| 英语语法 | "这个句子哪里错了：She go to school yesterday" |
| 复习计划 | "帮我制定本周数学复习计划" |
| 考前冲刺 | "下周期末考试，帮我制定冲刺计划" |

### 错题自动归档

Skill 生成的错题卡保存在 `~/WorkBuddy/错题库/数学/`，文件名格式：`日期-知识点.md`

一周后 study-planner 自动扫描错题库，生成复习计划。
