# 珞妤 · WorkBuddy 初中全科学习方案

> 米迦勒团队 · 四兄弟联合出品 · 2026.07

---

## 一、方案概述

围绕 **WorkBuddy** 打造初中全科智能学习系统。核心功能：

| 功能 | 覆盖 | 实现方式 |
|:--|:--|:--|
| 错题分析 | 数学/语文/英语 | WorkBuddy Skill → 拍照即分析 |
| 错因归类 | 5类错因体系 | 自动分类 + 路西法审核 |
| 新题生成 | 数学为主 | 同知识点 3 道梯度题 |
| 学习计划 | 全科 | 基于错题库的艾宾浩斯复习表 |
| 作文批改 | 语文/英语 | 多维度评分 + 修改建议 |

## 二、模型策略

### 按任务分配（国内模型）

| 任务 | 模型 | 理由 |
|:--|:--|:--|
| **数学解题** | DeepSeek R1 | chain-of-thought 推理，国内数学准确率最高 |
| 数学验算 | DeepSeek R1（换方法） | 同一模型、不同方法交叉验证 |
| 语文/作文 | Kimi K2.7 | 中文理解力强，128K 长上下文 |
| 英语 | 通义千问 Max | 中英双语平衡 |
| 学习计划 | DeepSeek V3 | 通用推理，性价比高 |

### 为什么数学用 DeepSeek R1？

- 国内唯一有公开 benchmark 证明数学能力的推理模型
- MATH 基准测试准确率国内第一
- 自带思维链，能展示推导过程（对学生学习很重要）
- API 便宜：¥1/百万 token，初中生一天不到 5 分钱

### 双重保险

1. Skill 内置**交叉验证**：同一题用两种方法算
2. **路西法抽查**：每周从错题库随机抽 3 题独立验算
3. 答案不一致 → 标记人工复核

## 四、部署步骤

### 在女儿电脑上

```bash
# 1. 把整个 learning/ 文件夹拷到女儿电脑
# 2. 运行部署脚本
bash deploy.sh

# 3. 编辑模型配置 → 填入 API Key
open ~/.workbuddy/models.json

# 4. 重启 WorkBuddy
```

### 获取 API Key（3 步，5 分钟）

| 平台 | 地址 | 说明 |
|:--|:--|:--|
| DeepSeek | platform.deepseek.com | 注册即送 500 万 token |
| Kimi | platform.moonshot.cn | 注册即送额度 |
| 通义千问 | dashscope.aliyun.com | 百万 token 免费额度 |

> 3 个都注册，总花费 0 元。月消耗 < ¥10。

### 在爸爸电脑上（路西法抽查）

```bash
# 每周运行一次
bash lucifer-review/verify.sh
# 报告自动生成在 ~/路西法-抽查报告-日期.md
```

## 五、使用方式

女儿在 WorkBuddy 里这样说：

| 场景 | 怎么说 |
|:--|:--|
| 数学错题 | "帮我分析这道题：[粘贴题目]" 或直接截图 |
| 语文作文 | "帮我批改这篇作文：[粘贴]" |
| 英语语法 | "这个句子哪里错了：She go to school yesterday" |
| 复习计划 | "帮我制定本周数学复习计划" |
| 考前冲刺 | "下周期末考试，帮我制定冲刺计划" |

### 错题自动归档

Skill 生成的错题卡保存在 `~/WorkBuddy/错题库/数学/`，文件名格式：`日期-知识点.md`

一周后 study-planner 自动扫描错题库，生成复习计划。
