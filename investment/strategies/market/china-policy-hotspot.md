# 中国市场特点与应对（大盘规则 · 2026-08-27 更新）

> 原则：大盘在前，决定“做不做、给多少仓位”；个股在后，决定“买哪只、何时买卖”。

## 一、判断优先级
1. 大盘与政策：政策转向、监管降温、两市成交额、涨停/跌停家数、涨跌家数 → 决定仓位上限。
2. 板块热度与主力资金：最强题材、龙头连板、板块资金净流入 → 决定做什么。
3. 个股技术动量：量价、突破、换手、KDJ/RSI/MACD → 决定何时买卖。
4. 估值与盈利：只作排除项，不作核心买入理由。

## 二、大盘状态分级与仓位上限
| 状态 | 判定 | 仓位上限 | 个股操作 |
|:--|:--|:--:|:--|
| 强 | 上证站上5/20日线，两市放量，涨多跌少 | ≤ 满仓 | 正常按信号买核心 |
| 震荡偏强 | 未破5/20日线，量能正常 | ≤ 70% | 只买最强主线+最强个股 |
| 弱但未破位 | 上证下跌但未破3800/20日线 | ≤ 半仓 | 仓位降半，买点更严 |
| 破位 | 上证跌破3800或创业板跌破MA20 | 只卖不买 | 不新开仓，逢反弹减 |
| 系统性风险 | 放量长阴/跌停潮/龙头集体炸板/监管降温 | 0 | 无条件空仓，不猜底 |

## 三、大盘生命线（硬线）
- 上证跌破 3800 → 只卖不买。
- 上证跌破 20 日线且两市成交连续 3 日缩量 → 只防守不加新仓。
- 出现跌停潮、高位龙头集体炸板、监管降温 → 无条件空仓。

## 四、当天预测大盘走弱，个股买不买
- 预测弱但没破位 → 只买最强主线+最强个股，仓位降半，买点更严。
- 预测弱且跌破生命线/放量长阴 → 不买，只卖。
- 跌停潮/炸板/监管降温 → 空仓。

## 五、已持仓遇大盘突然走弱
- 用两把尺：大盘尺定仓位，个股尺定买卖点，不互相替代。
- 个股没破分时均线/止损，大盘只是普通回落 → 持有，不加仓，止损上移到成本价或分时均线。
- 个股也跌破分时均线/买入价 -5% → 减半或清仓。
- 大盘放量长阴/跌破3800/跌停潮 → 无论个股多强，先降半仓。
- 不确定时“减半不减全”：先卖一半控制风险，留一半等确认。

## 六、平衡点
- 大盘定仓位上限，个股定买卖触发；预测只调仓位，不替代止损/止盈。
- 宁可减半再回补，不用“全卖 / 死扛”二选一。

## 七、盘前信息扫描（必做，2026-08-27 起）
- 每次大盘/个股分析前，先扫一遍信息面，不只看财经，还要看政策、军事、外交、行业监管、海外市场。
- 国内源：东财快讯、新浪财经7x24、证券时报、财联社、央行/证监会公告。
- 国外源：美联储/美国宏观、地缘政治、隔夜美股欧股、大宗商品（金/油/铜）、汇率与北向资金。
- 输出到当日 preopen 文件，标出“利好 / 利空 / 中性”及可能影响的板块。
