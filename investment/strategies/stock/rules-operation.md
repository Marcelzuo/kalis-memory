# 操作规则（2026-08-31 定稿 · 进取账户协议）

> 资金、仓位、止损、止盈、换股、每日节奏。股票进取账户与 ETF 定投账户完全分离。
> 老板买入后报买入价，按此给信号。

## 一、账户定位（两条线分离）
- ETF 定投账户：保守底盘，定期定额买入，中途不操作，不适用本规则。
- 股票进取账户（当前 2 万，后续可增资）：追求收益最大化，接受风险；风险靠“止损纪律 + 账户级熔断”控制，不靠分散。

## 二、候选池与每日选股
- 候选池 = 核心 3 + 候补 3 = 6 只；每日收盘终筛，午间半日重筛补充。
- 每日从池中挑“真正踩中信号”的股票，数量不固定：**0 / 1 / 2 / 3 只**。
- 入场信号（缺一不做）：回踩买区下沿 + 分时均线放量翻红 + 盈亏比≥2（-5% 止损 → 目标≥+10%）+ 题材资金前排。
- 无信号 → 空仓；有几只合格就买几只，不强制分散、不强制满仓。

## 三、仓位（灵活分配，按信号强弱）
- 单票一次性买入，不分批、不摊平。
- 买 1 只：可满仓（≤100%）。
- 买 2 只：按信号强弱分配（约 6:4 或 7:3），不平均。
- 买 3 只：按信号强弱分配（约 5:3:2）。
- 原则：信号越强、盈亏比越高、越贴近买区下沿 → 仓位越大；现金至少留够一手最低价候选。

## 四、止损与止盈（一次性，纪律优先）
- 止损：买入价 -5%，买入即挂条件单，触价全清，不撤单、不扛单。
- 止盈：买入价 +10%，同上全清。
- T+1：当日新买次日才能卖；盘中触线仅标记，次日开盘价无条件执行。
- 禁止：向下摊平、补仓、盘中临时改单、开盘情绪化追高。

## 五、账户级熔断（真正的风控）
- 权益从峰值回撤 ≥20% → 单笔仓位降半（≤50%）。
- 回撤 ≥30% → 停止开新仓，复盘 1 周再重启。

## 六、每日节奏（两段式）
1. 9:00 前：盘前预测 + 三情景压力测试（温和回调 / 黑天鹅 / 系统性），给大盘区间 + 池内买点/止损/止盈 + 主线。
2. 9:15–9:25：只看集合竞价异动。
3. 9:30–9:45：只看不买。
4. 9:45–10:30：首次确认，池内信号才买。
5. 11:30：午间全市场重筛 3 只 → 下午观察名单。
6. 13:00–14:30：观察名单 + 原池，等回踩翻红。
7. 14:30–15:00：尾盘定型，合格才买（T+1 隔夜）。
8. 15:00 收盘：午间 3 只 + 原池复核，留/重筛，定次日池；对账写回 `lessons-log.md`。

## 七、换股与失效线
- 触发换股：跌破 -5%；题材 3 日不发酵 / 龙头断板 / 炸板；主力连续净流出 / 缩量失势；技术破位；大盘破位。
- 失效线：跌破买区下沿 / 关键支撑、主线断板、资金连续流出 → 剔除或降候补。
- 每日重筛 ≠ 每日强制换；触发才动，T+1 次日开盘执行。

## 八、持股周期与周末
- 默认短线 1–5 个交易日，上限 10 个交易日；触发优先，未触发按每日重筛定去留。
- 过周末默认不轻易满仓：浮亏/平手周五减清；浮盈强主线可留 ≤半仓。

## 九、台账与考核
- 每笔记：买价、止损、止盈、实际触发价、盈亏比、是否按规则执行。
- 保本胜率 = 1/(1+R)；R=2 → 约 33%，扣费后约 35%；攒 30 笔看胜率是否达标，不达标调参数。
- 月度回测四件套：胜率 / 盈亏比 / 期望值 / 最大回撤。
