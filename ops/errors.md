## 2026-08-26 · 米迦勒（分派 + 联网 + 派工复用）

### 1. 兄弟分派工具混淆（反复犯）

**错误：** 想并行派三兄弟时，直接调 `spawn_agent`，得到 `unsupported call: spawn_agent`，还误以为环境不可用。

**事实：** 本环境没有 `spawn_agent` 这个兄弟机制。正确调度走三条 CLI，且要先查 `ops/team.md`：
| 兄弟 | 调用 | 领地 |
|------|------|------|
| 玛门 | `claude -p "任务" --allowedTools "Bash(*) Edit Read"` | HTML/CSS/JS·素材·图片·视频·代码 |
| 撒旦 | `openclaw agent --local --agent main --message "任务"` | 浏览器·GUI·截图·抓取 |
| 路西法 | `hermes -z "任务"` | 文案·审查·知识库·规则 |

**教训：** 分派前先 `which claude/openclaw/hermes` 确认，再查 `team.md` 决定派谁。文案归路西法，米迦勒不碰文案只终审。

### 2. 联网核验走错通道 + 死磕

**错误：** 核验执信中学信息时，先试维基百科、必应、DDG 等国外通道，反复重试拿不到内容，浪费多轮。

**事实：** 老板未开 Clash，国外通道不通；`opencli doubao ask` 需要 Chrome 插件连接，也失败。正确做法是直接 `curl` 国内搜索引擎抓取网页：
- 搜狗：`curl -sL -A "Mozilla/5.0..." "https://www.sogou.com/web?query=<url编码关键词>"`，再 `python3` 剥 HTML 标签搜关键词
- 本次成功确认：执信中学1921年创办、孙中山纪念朱执信创办、校训“崇德瀹智”

**教训：** 联网先走国内通道（搜狗/百度），失败换 query 不换通道死磕；核验信息先做搜索台账 `site/query/count/status`。`opencli` AI 源（doubao 等）要先确认浏览器插件状态，不可裸调。

### 3. 路西法二次派工丢上下文（新犯）

**错误：** 路西法第一次交稿后，派“只改三处”的修订任务，只传修改意见没传原文，结果它输出了完全无关的医药工程师稿。

**事实：** `hermes -z` 单次调用无会话记忆。要求“只改不重写”时，必须把完整原稿原文贴回任务里，再附修改点。

**教训：** 对路西法做增量修订，任务必须 = 原文全文 + 修改清单；禁只发“把 X 改成 Y”。
