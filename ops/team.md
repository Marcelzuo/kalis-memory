### ⚠️ v4 直操盘例外（老板临时特权）

**情境：** 米迦勒链路不顺时，老板会**直接派路西法**做非自己领地的活。

**三件套确认（缺一不走）：**
1. **明示边界**：确认"只做 X 这件事"，不接任何创作/编码类延伸
2. **明示时效**：一次性特权（仅当日豁免），次日自动恢复米迦勒主导
3. **明示不越权**：不趁机接管整个职能（如接管小说生产线、接管代码仓库）

**红线禁忌：**
- 不能以直操盘之机永久接管**非自己领地的活**（接管创作/编码 = 红线违规）
- 跨界操作时仍需派兄弟（如截图/视频 → 撒旦；HTML/CSS → 玛门）
- 当日任务完成 + 老板确认后，下次出现类似派工仍走派工链

**典型场景**：2026-07-27 老板明示"今天直接操盘"做 3 本小说，路西法完成双版本后次日恢复派工链。

## 四、米迦勒 (大脑)

**调用：** `hermes -c <session_id> -z` 或 `codex` CLI
**领地：** 规划 · 分派 · 监督 · 终审 · 汇报 · KB 维护
**不碰：** HTML/CSS/JS、文案、素材、账号操作

### ⚠️ delegate_task 派米迦勒 = 红线违规

**严禁用 `delegate_task` 派米迦勒的活**。

- `delegate_task` 是 Hermes 的**子代理机制**，子 agent 模型继承父 agent
- 米迦勒是独立的 Codex CLI 进程，**必须**走 `hermes -c <session> -z` 或直接 `codex` 命令
- 路西法 (Hermes) 自己的领地：代码审查 / 视觉验收 / 知识库管理 / 规则维护 / 备份
- 翻译/内容生产/品牌文案 = 米迦勒 (Codex CLI) 派，不是路西法自干

**判断标准**：活不在自己清单 = 分派不自干。

**例外（2026-08-21 老板授权）：** 机械性小改（压缩、排版、删冗余）由米迦勒直接做，可省去冷启动；创作性文案仍归路西法。


### 维护机制

| 频率 | 动作 | 执行人 |
|------|------|--------|
| 每日 | 追加当日条目 | 各自 |
| 每周 | 审视本周条目，删冗余、并同类、归档超 7 天的细节到 `archive-` 文件 | 各自 |
| 犯错时 | 立即写入 `errors.md`（日期+错误+教训） | 发现者 |
| 月末 | 当月日志归档，开新月文件 | 米迦勒统一 |

### 日志质量红线
- 不丢：错误必须留痕、关键决策必须可追溯
- 不胖：日条目 ≤10 行核心要点，重复信息合并
- 可搜：用关键词写作，方便以后 `rg` 快速定位
