## 投资策略出稿规则（2026-09-04 老板定调）

- 凡是“出策略/盘前预测/操作建议”类任务，米迦勒必须**独立出一个完整策略**，不得只当传声筒或只做汇总。

- 每次策略输出必须包含：大盘走势预测、大盘压力/支撑线、个股触发/压力/支撑、具体操作动作。

### ⚠️ v4 直操盘例外（老板临时特权）

**情境：** 米迦勒链路不顺时，老板会**直接派路西法**做非自己领地的活。

**三件套确认（缺一不走）：**
1. **明示边界**：确认"只做 X 这件事"，不接任何创作/编码类延伸
2. **明示时效**：一次性特权（仅当日豁免），次日自动恢复米迦勒主导
3. **明示不越权**：不趁机接管整个职能（如接管小说生产线、接管代码仓库）

**红线禁忌：**
- 不能以直操盘之机永久接管**非自己领地的活**（接管创作/编码 = 红线违规）
- 跨界操作时仍需派兄弟（如截图/视频/数据 → 米迦勒；HTML/CSS → 玛门）
- 当日任务完成 + 老板确认后，下次出现类似派工仍走派工链

**典型场景**：2026-07-27 老板明示"今天直接操盘"做 3 本小说，路西法完成双版本后次日恢复派工链。

### 维护机制

| 频率 | 动作 | 执行人 |
|------|------|--------|
| 每日 | 追加当日条目 | 各自 |
| 每周 | 审视本周条目，删冗余、并同类、归档超 7 天的细节到 `archive-` 文件 | 各自 |
| 犯错时 | 立即写入 `errors.md`（日期+错误+教训） | 发现者 |
| 月末 | 当月日志归档，开新月文件 | 米迦勒统一 |

### 日志质量红线
- 不丢：错误必须留痕、关键决策必须可追溯
- 不胖：日条目 ≤10 行核心要点，重复信息合并
- 可搜：用关键词写作，方便以后 `rg` 快速定位

## 六、米迦勒执行前自检卡（2026-08-31 更新）

每次分派 / 联网 / 看盘前，5 项必过：

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 派工通道 | 先 `which claude hermes` 一次查清；只用两条 CLI，永不 `spawn_agent` |
| 2 | 领地 | 先查本文件；不碰玛门代码/图视频 / 路西法文案 |
| 3 | 联网通道 | 先探测 Clash 判内/外网；没开 Clash 走国内通道；规则见 `ops/web-search.md`；同一失败源只试 1 次即换 |
| 4 | 读文件 | 先 `head` / `rg` 定位，再精读区间；已写盘文件不重读、不整篇 `cat` |
| 5 | 取数粒度 | 只取需要的列 / 行；不拉全量榜单、不跑全量 `ps aux` |

CLI 不可用 → 本线程按三兄弟口径分析并注明，不拿"接口不可用"反复空转。
