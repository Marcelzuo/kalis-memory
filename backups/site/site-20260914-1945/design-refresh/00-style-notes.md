# 00 统一风格样稿 · 设计说明

> 样稿：Our Picks Hook 1「On-the-ground value」内容卡片
> 画布 1440×810（16:9 参考，上线时按卡片实际列宽等比缩放）

## 风格一句话

**编辑式极简**：暖白底 + 大字报式标题 + 细线分隔 + 单块材质纹理图，高端、克制、有呼吸感。无电商大促风、无 AI 味。

## 1. 字体层级（全站 Montserrat）

| 层级 | 规格 | 用途 |
|:--|:--|:--|
| Logo | 冠线 1px / KALIS Light 300 / TORIK ExtraLight 200，按 VI 铁律 | 页眉字标 |
| Title | 42px · Light 300 · `#000` · 行高 1.16 | 卡片标题（两句各占一行，句号后强制断行） |
| Kicker | 11px · Light 300 · `#2D2D2D` · 全大写 · 字距 0.32em · 前置 40px 细线 | 眉题（On-the-ground value） |
| Body | 15.5px · Light 300 · `#2D2D2D` · 行高 1.78 · max-width 56ch | 正文（约 4 行） |
| CTA | 15px · Light 300 · `#000` · 1px 下划线 + `→` | 行动点 |
| 序号 | 44px / ExtraLight 200，当前卡 `#000`、其余 `#B9B1A4` | 系列索引（01 / 03） |

## 2. 颜色使用

- 暖白 `#FAF8F5` 页面底 · 黑 `#000` 标题 · 深灰 `#2D2D2D` 正文/眉题 · 灰 `#888` 冠线/TORIK/装饰细线。
- `#C9A96E` **未使用**（仅特种工艺，数码 Logo/装饰线禁用）。
- 对比度：正文 `#2D2D2D` on 暖白 ≈ 11:1 ✓；标题 `#000` ≈ 19:1 ✓。
- ⚠️ **决策点**：`#888` on 暖白仅 ≈ 3.4:1，低于 4.5:1，故小号正文/眉题一律用 `#2D2D2D`，`#888` 只留给冠线、TORIK、装饰细线和大字号。请老板确认此取舍。

## 3. 图片处理（素材规则）

- 样稿图块 = **纯 CSS 材质纹理**（暖棕渐变 + feTurbulence 颗粒）+ **单色家具线稿**（沙发轮廓 + 缝线虚线）。非实拍、非 AI 生图、无人物、无品牌。
- 三张卡片图块母题可轮换：**01** 皮料/布料纹理 + 家具轮廓（本站）· **02** 缝线/五金细节（独立验货）· **03** 港口/集装箱空镜（Q4 出货）。
- 红线：无人物/手/脸/身体部位、无国外品牌 logo、无具体数字；实景图由老板提供。

## 4. 留白规则

- 页面四周 48px（上下）/ 56px（左右）；主网格 gap 64px。
- 图块 440px 宽 × 满高（左），文字列 824px（右）。
- 标题与正文之间 72px 细线分隔，线上下各 ~28px。
- 呼吸感 = 大留白 + 单一主视觉 + 克制细线，不堆信息。

## 5. 延展规则

### Our Picks 3 张（同一版式）
- 统一结构：图块(左) + kicker/标题/正文/CTA(右) + 右上角序号。
- 只换四样：kicker、标题两句、正文、CTA、图块母题。
- 序号「当前实 / 其余虚」表达系列感（当前 `#000`，其余 `#B9B1A4`）。

### Why Us 1 张（复用叙事层）
- 复用：暖白底、细线、kicker + 大标题 + 正文层级。
- 统计四栏（Factories / Years / EU Clients / Rates）用「标签 + 短句」版式，数字栏留白不写具体数。
- 差异：整页叙事版式（非卡片），标题更大（约 56px），正文分两段。

### How It Works 4 步（复用序号系统）
- 复用：序号系统（01–04，替代 Our Picks 的 01–03）、kicker 层级、细线。
- 差异：四步并排/纵向排布，每步 = 序号 + 步骤标题（约 20px）+ 描述（15px），步骤间细线连接。

## 6. 尺寸与响应式

- 画布 1440×810；上线时随卡片实际列宽等比缩放，字号同步缩，Logo 按 VI「随字号等比」处理。
- 移动端：图块上移、文字下移（竖排堆叠），标题降至约 28px 仍保持两句两行节奏；文字 1 秒可读。
