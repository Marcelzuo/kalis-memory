# SEO / AI 推广调研 · 2026-11-06

## 一、Google 官方口径（AI Features and Your Website）

来源：Google Search Central 官方文档。要点：

1. AI Overviews / AI Mode 没有额外的技术要求，也没有专门的提交入口。
2. 页面必须可被索引、允许展示 snippet；否则不会进入 AI 功能。
3. 基础 SEO 仍然有效：robots、内部链接、页面体验、正文文本、图片/视频、结构化数据与可见文本一致。
4. 不需要专门的 AI 文件或特殊 schema；`llms.txt` 是补充，不是排名因素。
5. GSC 的 Web 搜索表现包含 AI 功能带来的流量；AI 点击通常质量更高。

对本站的直接结论：先把可索引、可 snippet、内容与 schema 一致做好，再谈 AI 文件。

## 二、Google autosuggest 关键词簇

| 种子词 | 下拉扩展 |

| furniture sourcing | from china / jobs / solutions / website / agent foshan / company / companies india / vietnam |
| import furniture china | to australia / usa / uk / canada / pakistan / kenya / reddit |
| furniture supplier china | manufacturer / chair / companies / restaurant / event / office / outdoor |
| sofa manufacturer china | sofa factory / couch manufacturer / suppliers / compressed sofa / sofa bed / leg |
| furniture agent | agent foshan / sourcing agent foshan / chinese furniture agent |
| furniture quality inspection | inspector / QC order 2025/2026 / checklist pdf |

- 没有 Belgium / EUDR 的直接 suggest，说明这是低竞争长尾，不是高流量大词。
- 机会优先级：`furniture quality inspection checklist`、`sofa manufacturer china`、`furniture sourcing agent foshan`、`import furniture from china to uk/usa`。

## 三、通道状态

- Clash 7890 可用；Google autosuggest API 可用。
- Google/Bing/DDG 直接 curl 被反爬或返回空；`opencli google` 因 Browser Bridge 未连接失败，不反复重试。
- 搜狗可用（标题级）；PageSpeed API 429 配额耗尽，不依赖。
- 结论：外网检索由米迦勒按需拉取；不把 LLM 当爬虫。

## 四、免费流量动作优先级

1. 修可索引与内链：clean URL、canonical、sitemap、FAQ 可见文本。
2. 内容：每周 1 篇，answer-first，表格/清单/FAQ，方便 AI 引用。
3. 收录：GSC 重提 sitemap + 两篇新文 Request Indexing；IndexNow ping Bing/Yandex。
4. 站外：Europages / Kompass 免费目录、LinkedIn/FB/IG 内容复用；不做冷邮件、不投广告。
5. 30 天验证：AI 会话 ≥10、询盘 ≥3、目标词 GSC 点击 >0。
