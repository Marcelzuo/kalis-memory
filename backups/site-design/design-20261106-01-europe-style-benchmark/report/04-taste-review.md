# KALIS TORIK 首页审美取舍 · 路西法判断

## 1. 结论
"色彩更丰富"=摄影/材料/陈列更丰富，不是 UI 更花。11 个欧洲样本 UI 均中性克制，颜色由家具、纺织、木材、空间承担。B2B 买家看"你懂不懂货"：彩色按钮传达不了，一张皮革近景可以。UI 越花，照片越被稀释，越像模板站。

## 2. 欧洲 vs 美国（页面行为）
欧洲：①首屏给场景/材料/静物，转化入口藏深一层；②导航走 Collections/Stories/Professionals，先语境后商品；③颜色来自摄影，UI 近乎无色。
美国：①首屏即 Shop by category/Sale，路径最短；②导航直给功能词（Reviews/Find a store）；③UI 可承担促销色。

## 3. 最危险的 5 个廉价信号（现站已中 4 个）
①金色 #C9A96E 用在按钮/标签/步骤圈——违反红线（金仅限特种工艺），金边 UI 是工厂模板第一特征；②首屏黑底零产品零场景，欧洲买家读作"空壳贸易商"；③全页仅 4 张实景图，其余靠 JS 缩略图撑；④所有 H2 同字号同大写同居中，section 均质如默认模板；⑤产品卡 contain+米色大留白=目录感，非陈列感。

## 4. 三方向
A 保守增强：配色不动，加实景图密度、统一卡片比例、降金色面积；布局微调，无新 signature。理由：改动最小，治不了"首屏空洞"的根。
B 欧洲编辑式（推荐）：UI 收为白/暖白/黑/灰，金色撤出全部 UI；色彩交给摄影（暖木、皮革棕、陶土、橄榄绿来自货物实拍）。字体仍 Montserrat，H2 拆三档、左对齐、大小写混排。布局改整屏场景/左文右图/双联画，首屏放材料或成品近景。Signature：材料特写作章节分隔，顺序对齐欧洲结构（场景→系列→材料→验货故事→询价）。理由：契合验货定位，放大"看得懂材料"这一资产。
C 明显更彩色：UI 多色块、彩色标签。不推荐：与欧洲样本行为相反，与品牌色系冲突，六语言维护成本高，促销感伤 B2B 信任。

## 5. 推荐 B · 优先级
1.首屏加大幅材料/成品实拍（无人物无手），Logo+短句压暗蒙层；2.金色撤出所有 UI，CTA 改黑底白字细边框；3.实景图扩到每 section 至少 1 张，产品卡统一陈列底与比例；4.H2 拆三档、左对齐，打破居中均质；5.导航对齐欧洲词：Collections/Materials and Craft/Process/Inquiry。
绝对不动：①Logo 结构（灰冠线+黑 KALIS+灰 TORIK）；②favicon；③六语言镜像骨架与 B2B 定位（无购物车、无价格、无 CIF 承诺）。

## 6. 去模板化规则（欧洲 B2B 语境）
①标题须有具体内容，禁裸 "About Us/Why Choose Us"；②图像禁白底悬浮抠图，一律带材质上下文（木纹、织物、光线、车间空镜）；③文案用供应链行话：lead times、QC、consolidation、container load，删营销形容词；④不出现无来源数字、价格、工厂名；⑤六语言共用同一图像与版式骨架，只换文本层，禁单语私自"美化"。
